# don't sleep

Лёгкое приложение для Windows: быстрые заметки и напоминания, которые не дают пропустить важное.
Живёт в трее, всё хранится локально, один exe — без установки и без интернета.

## Быстрая запись

Из любого приложения нажми **Ctrl + Shift + Space** — появится окно, набери текст и жми **Enter**.
Всё, что нужно, — две секунды.

**Alt + Shift + Space** открывает **обзор**: окно с поиском, где одной строкой видны все напоминания
(с временем) и последние заметки. Стрелки + Enter — перейти к элементу в главном окне,
клик по квадратику слева — отметить напоминание сделанным.

Правило одно: **без `@` — заметка, с `@` — напоминание.**

| Что набрать | Что получится |
|---|---|
| `купить молоко` | заметка |
| `@14:00 позвонить в банк` | напоминание сегодня в 14:00 (если время прошло — завтра) |
| `@9 зарядка` | напоминание в 09:00 |
| `@14:30 завтра встреча с Петей` | напоминание завтра в 14:30 |
| `@28.10 09:00 сдать отчёт` | напоминание 28 октября в 09:00 |
| `@через 30 мин забрать посылку` | напоминание через 30 минут |
| `#работа отправить документы` | заметка с тегом `#работа` |

`Esc` — закрыть окно без сохранения.

## Что умеет

- **Заметки** — список, поиск по тексту и тегам, закрепление, удаление.- **Напоминания** — время, отметка «сделано», удаление; вовремя всплывает уведомление со звуком.
- **Трей** — приложение не мешает; левый клик открывает окно, правый — меню (открыть / быстрая заметка / выход).
- **Автозапуск** при входе в Windows (включается в настройках).
- **Уведомления** — всплывают в правом нижнем углу даже при свёрнутом окне.

## Данные

Всё лежит в `%APPDATA%\dontsleep`:

- `dontsleep.db` — заметки и напоминания (SQLite);
- `config.json` — настройки;
- `dontsleep.log` — журнал;
- `webview\` — кэш WebView2.

Резервная копия — просто скопировать `dontsleep.db`.

## Сборка

### Быстро: скрипт

Готовый бинарник можно не собирать — скачайте его из [Releases](https://github.com/rogazzzi/don-t_sleep/releases/latest)
(файл `dontsleep.exe`, ~11 МБ).

Если нужна своя сборка, на Windows-хосте достаточно Docker (Go ставить не нужно):

```powershell
.\build.ps1
```

На выходе — `dist\dontsleep.exe`.

### Вручную

Из корня репозитория (папка, где лежит `go.mod`):

```powershell
docker run --rm `
  -v "${PWD}:/work" -v "go-mod-cache:/go/pkg/mod" -w /work `
  -e GOOS=windows -e GOARCH=amd64 -e CGO_ENABLED=0 `
  -e GOPROXY=https://goproxy.cn,direct `
  golang:1.26 go build -ldflags="-s -w" -o dist/dontsleep.exe .
```

Почему `GOPROXY=https://goproxy.cn,direct`: с прокси по умолчанию загрузка модулей
(`modernc.org/libc` и другие) на некоторых сетях идёт со скоростью ~30 КБ/с.
Зеркало отдаёт те же модули в разы быстрее. Если у вас всё качается нормально —
параметр можно убрать.

Named volume `go-mod-cache` кэширует модули между сборками: первая сборка дольше,
последующие — около минуты.

### Требования

- **Docker Desktop** (сборка в контейнере `golang:1.26`);
- **WebView2 Runtime** — движок интерфейса. В Windows 10/11 уже установлен;
  на старых системах — [отдельный установщик](https://developer.microsoft.com/en-us/microsoft-edge/webview2/).

### Что внутри exe

Интерфейс (`web/`) вшит в бинарник через `embed`, поэтому рядом с exe ничего не нужно.
База — встроенный SQLite (без внешнего сервера), данные пишутся в `%APPDATA%\dontsleep`.

### Проверка сборки

```powershell
dist\dontsleep.exe -no-window
```

Выведет адрес локального сервера — можно открыть интерфейс в браузере
и проверить API (`/api/health`, `/api/notes`, `/api/reminders`).

### Тесты

```powershell
docker run --rm -v "${PWD}:/work" -v "go-mod-cache:/go/pkg/mod" -w /work `
  -e GOOS=windows -e GOPROXY=https://goproxy.cn,direct `
  golang:1.26 go test ./...
```

Тесты парсера (`parse_test.go`) проверяют разбор `@14:00`, `@завтра 9:00`,
`@28.10 18:00`, `@через 30 мин` и перенос прошедшего времени на завтра.
